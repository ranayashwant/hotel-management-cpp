# 🏨 Hotel Management System — C++

A simple console-based Hotel Management System built while learning C++ fundamentals. This was one of my first projects, focused on practicing loops, arrays, structs, and switch-case logic.

---

## 📌 About

This project simulates basic hotel operations through a menu-driven command-line interface. No databases, no frameworks — just core C++ to understand how programs are structured and how data is managed in memory.

---

## ✨ Features

- 📋 View all rooms with current status (Available / Booked)
- 🛏️ Book a room with guest name and number of days
- 🧾 Check out a guest with auto-generated bill
- 🔍 Search for a guest by name
- ✅ View only available rooms

---

## 🛠️ Concepts Used

- `struct` to group room data
- Arrays to store multiple rooms
- `while` loop for continuous menu
- `switch-case` for menu navigation
- `if-else` for input validation
- Basic `cin` / `cout` for I/O

---

## 🚀 How to Run

**Requirements:** Any C++ compiler (g++, MinGW, etc.)

```bash
# Compile
g++ hotel_management.cpp -o hotel

# Run (Linux / Mac)
./hotel

# Run (Windows)
hotel.exe
```
